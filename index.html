Orion Belt packages

Signed package repositories for Orion Belt v1.3.1: the server and agent for Linux, and the osh, ocp and oadmin clients for Linux, macOS, Windows, the BSDs, illumos and Solaris.

Signing key: orion-belt.asc — fingerprint F1E47F7B036D5202262E174F613B2217A8958DA9. Release files: GitHub release v1.3.1.

Quick install

curl -fsSL https://pkgs.orion-belt.dev/install.sh | sh                 # clients (Linux, macOS, BSD, illumos)
curl -fsSL https://pkgs.orion-belt.dev/install.sh | sh -s -- agent      # agent (Linux)
curl -fsSL https://pkgs.orion-belt.dev/install.sh | sh -s -- server     # server (Linux)
irm https://pkgs.orion-belt.dev/install.ps1 | iex                       # clients (Windows)
scoop install https://pkgs.orion-belt.dev/scoop/orion-belt.json         # clients (Windows, scoop)

On Linux the installer adds the repository below for your package manager, so upgrades arrive with the system's.

Debian, Ubuntu, Raspberry Pi OS

Architectures: amd64 arm64 armel armhf i386 loong64 ppc64el riscv64 s390x

sudo curl -fsSLo /usr/share/keyrings/orion-belt.gpg https://pkgs.orion-belt.dev/orion-belt.gpg
echo "deb [signed-by=/usr/share/keyrings/orion-belt.gpg] https://pkgs.orion-belt.dev stable main" | sudo tee /etc/apt/sources.list.d/orion-belt.list
sudo apt-get update && sudo apt-get install orion-belt-agent   # or orion-belt, orion-belt-tools

Fedora, RHEL, Rocky, Alma, Amazon Linux, openSUSE

sudo curl -fsSLo /etc/yum.repos.d/orion-belt.repo https://pkgs.orion-belt.dev/orion-belt.repo
sudo dnf install orion-belt-agent        # or yum install

sudo zypper addrepo https://pkgs.orion-belt.dev/orion-belt.repo   # openSUSE / SLES
sudo zypper install orion-belt-agent

Alpine

Architectures: aarch64 armhf armv7 loongarch64 ppc64le riscv64 s390x x86 x86_64

sudo wget -O /etc/apk/keys/orion-belt.rsa.pub https://pkgs.orion-belt.dev/apk/orion-belt.rsa.pub
echo "https://pkgs.orion-belt.dev/apk" | sudo tee -a /etc/apk/repositories
sudo apk update && sudo apk add orion-belt-agent

Arch Linux, Arch Linux ARM

Architectures: aarch64 armv7h i686 x86_64

curl -fsSL https://pkgs.orion-belt.dev/orion-belt.asc | sudo pacman-key --add -
sudo pacman-key --lsign-key F1E47F7B036D5202262E174F613B2217A8958DA9
printf '[orion-belt]\nServer = https://pkgs.orion-belt.dev/archlinux/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Sy orion-belt-agent

Services

The server and agent packages install their service for systemd, OpenRC, runit or SysV init, but do not start it until it is configured: /usr/lib/orion-belt/orion-belt-agent-service setup (or orion-belt-server-service) enables and starts it on any of them.

Containers

docker pull ghcr.io/orion-belt-dev/orion-belt-server:1.3.1
docker pull ghcr.io/orion-belt-dev/orion-belt-agent:1.3.1
