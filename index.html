Orion Belt packages

Static package mirror for Add agent install scripts.

Package base URL: https://orion-belt-dev.github.io/packages

Current release: VERSION / TAG (1.1.0). The console reads VERSION to prefill Package version.

Filenames match the install script (orion-belt-agent_${VERSION}_amd64.deb, etc.) plus GoReleaser originals (*_linux_amd64.*).

Container images (GHCR)

See CONTAINERS. Pull:

docker pull ghcr.io/orion-belt-dev/orion-belt-server:1.1.0
docker pull ghcr.io/orion-belt-dev/orion-belt-agent:1.1.0
